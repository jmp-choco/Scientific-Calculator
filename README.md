# Scientific Calculator

A simple menu-based Scientific Calculator built using Python.

## Project Overview

This project is a Python-based calculator that can perform both basic and scientific mathematical operations.

The program uses a simple command-line menu. The user selects an operation, enters the required values, and the program displays the result.

The project is divided into multiple Python files to keep the code organized and easy to understand.

---

## Features

The calculator supports the following operations:

### Basic Operations

- Addition
- Subtraction
- Multiplication
- Division
- Remainder
- Power

### Scientific Operations

- Square Root
- Square
- Cube
- Sine
- Cosine
- Tangent
- Logarithm
- Natural Logarithm
- Factorial

### Other Features

- Degrees and radians for trigonometric calculations
- Input validation
- Error handling
- Separate testing file
- Simple menu-based interface

---

## Technologies Used

- **Python 3**
- **Python `math` module**
- **Visual Studio Code**

No external Python libraries are required.
